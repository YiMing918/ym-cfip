④ 我的订阅链接（自动更新）

把这条链接填进客户端 / 优选订阅，客户端每次拉取拿到的都是最新聚合数据按你当前选项（地区、数量、门槛、运营商、端口、取数）现算的清单；上面选项一改，链接自动跟着变。「本地可用」是浏览器本地测的、上面的实时链接带不了 — 要把本地测通的结果变成订阅，用下面的快照链接；你的整套选项也可以存成分享链接收藏或发给别人。

⑤ 优选域名（可直接当节点地址用）

优选域名 = 解析到优质 CF 边缘的域名，效果类似优选 IP 但不用管 IP 失效。带「分流」的是社区维护的运营商分流域名（第三方维护，稳定性自行判断）；其余为 svip-s 收集的大厂 CF 域名。点「批量实测」从你当前网络逐个测它们的真实延迟与落地机房。

⑥ IPv6 池

IPv6 源不带地区标注，单独成池。能不能用取决于你本地网络的 IPv6 通道 — 点检测从你当前网络逐个试连。

⑦ 大池采样（官方段 · 未实测）

从 Cloudflare 官方公布的 IP 段（15 段、约 190 万个地址）随机采样。Anycast 不分地区、这批未经任何实测 — 正确用法是点「本地检测这批」，在你自己的网络里筛出能用的。

口径说明

本站只聚合、不测速。地区与速度来自各源在其测试地的标注：带测试地的源（如 svip-s 为陕西移动实测）离你越近参考价值越高；全国源是全国口径。四网（移动/电信/联通/广电）里，广电全网暂无公开实测源 — 选广电时给的是通用条目，广电用户请务必用「检测本地可用」在自家广电网络上实测筛选，那才是广电的真数据。
「本地可用 / 本地测速」是浏览器向每个 IP 发起 HTTPS 握手探测（证书不匹配 IP 会报错返回，测的是报错前耗时）：超时内有响应 = 你当前网络能连上该 IP:端口。它不等于节点可用或速度达标；开着代理测的是经代理的连通性，想测直连先关代理。清单测速为双测取低值，更稳。
「送复检站」会复制当前清单并打开你选的 IP 监测站（推荐 IPCheck.ing，也可自填任意监测站地址，选择保存在本地浏览器）。
优选域名由第三方维护，使用人数多时晚高峰可能变卡，作回退入口更合适。优选 IP 时效性强，失效条目以下一次聚合为准。
